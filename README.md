## Intended Use

**Primary focus** — Building systems where the ML/data layer and the full-stack layer meet: not just training a model, but shipping it behind an interface someone can use.

**Internship deliverables (Synent Technologies)**
- Data cleaning, visualization & EDA across Titanic, Iris, Netflix, Superstore, Mall Customers, and Stock Price datasets
- Customer segmentation and time-series sales forecasting
- Global Layoffs analysis (Python EDA) + Superstore Sales Dashboard (Power BI)
- House price prediction using Linear Regression, Decision Trees, and Random Forest

**Shipped & reachable** — [SpendMatrix](https://github.com/Dhruv-Adhiya/Spend-Matrix), a full-stack budget and expense tracker with JWT auth, category-wise analytics, and budget alerts.

## Limitations & Future Work

- **Production deployment** — stronger on modeling and analysis than on shipping ML models at scale; the pneumonia-detection work is the first step toward closing that gap.
- **Team-scale engineering** — most projects so far are solo or internship-scoped; actively looking for larger collaborative builds (the resume-job matcher / recommender system group project is a step in that direction).
- **Known bias** — training data (i.e. project history) skews toward structured/tabular datasets; deep learning on unstructured data (images, text) is newer ground.
